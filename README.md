
# Expense Tracker 💰

## About the Project

Expense Tracker is a simple React application that helps users manage their daily expenses. Users can add, edit, delete, search, and filter their expenses easily.

The application also displays the total expenses and category-wise spending summary.

## Features

- Add new expenses.
- Edit existing expenses.
- Delete expenses.
- View total expenses.
- Search expenses by title.
- Filter expenses by category.
- Filter expenses by date.
- View category-wise spending summary.
- Save expense details using Local Storage.
- Responsive design for different screen sizes.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Browser Local Storage

## Installation and Setup

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd expense-tracker
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npm run dev
```

Open the local URL shown in your terminal in your browser.

## How It Works

1. Enter the expense title.
2. Enter the amount.
3. Select an expense category.
4. Choose the expense date.
5. Click the Add Expense button.
6. View, edit, delete, search, or filter your expenses.

## Data Storage

This project uses Browser Local Storage to save expense details.

Your expenses remain available after refreshing the page in the same browser.
